# Madhav Ramdin · Portfolio

**Live site: [madhav-ramdin-portfolio.vercel.app](https://madhav-ramdin-portfolio.vercel.app)**

My personal portfolio website. I'm a Computer Science student (DEC, 3rd semester) at Cégep Marie-Victorin in Montréal, focused on networking and cybersecurity.

Built around what I care about most: **networking and cybersecurity**. The pages borrow from the tools of the trade (a `whois` card, an `nmap` scan of my skills, a `traceroute` through my history), and the hobbies section covers cars, swimming and the gym. The look is modeled on the pentest distros I use: a Kali-style Xfce desktop with an Applications menu (its entries keep Kali's real tool-category numbers), window title bars and the two-line `┌──(madhav㉿kali)-[~]` prompt. The first visit opens on a GRUB-style boot menu that picks the skin.

Skins: **Kali** (blue, the default), **Kali root** (red, `#` prompt) and **Parrot** (teal, with Parrot's `┌─[madhav@parrot]─[~]` / `└──╼ $` prompt). The boot menu also has a fail-safe entry that turns animations off. Applications → Reboot shows the boot menu again. Keyboard: `1` `2` `3` switch pages, `t` cycles skins.

## Auto-sync with GitHub

`scripts/sync-github.mjs` pulls my public repos, language totals and contribution graph from the GitHub API into `src/data/github.json`. The site reads that file at build time for the live stats, the activity graph, the "every public repository" list and the "pushed X days ago" labels.

`.github/workflows/sync-github.yml` runs the script every two days (and on demand from the Actions tab) and commits the file when it changes. Vercel is connected to this repo, so that commit redeploys the site. To sync by hand: `npm run sync` (uses `GITHUB_TOKEN`/`GH_TOKEN`, or the `gh` CLI login).

## Stack

React 19 · TypeScript · Vite · React Router

## Run it locally

```bash
npm install
npm run dev       # dev server on http://localhost:5173
npm run build     # type-check and build to dist/
npm run preview   # serve the production build
npm run lint      # oxlint
npm run sync      # refresh src/data/github.json from GitHub
```

## Editing content

All content lives in `src/data/`:

| File | What it holds |
|---|---|
| `profile.ts` | Intro, social links, whois card, traits, stats, toolbox and developer history |
| `themes.ts` | The skins in the skin menu (colors, fonts and prompt pieces live in `src/styles/theme.css`) |
| `github.json` | Generated by `npm run sync`; do not edit by hand |
| `projects.ts` | Featured projects, smaller builds and coursework |
| `experience.ts` | Work experience |

To show Instagram, set `INSTAGRAM_URL` and `INSTAGRAM_HANDLE` in `src/data/profile.ts`. Links without a URL are hidden.

## Deploying

`vercel.json` rewrites every path to `index.html`, so routes like `/projects` work on Vercel when you open them directly.
